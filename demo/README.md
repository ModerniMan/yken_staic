# 📋 תבנית סניף - מחולל ידידים

## איך להתאים לסניף חדש?

### שלב 1: שכפל את התיקייה
העתק את כל תיקיית `demo` ושנה את שמה לשם הסניף (למשל: `haifa`, `jerusalem`)

### שלב 2: החלף את ה-Placeholders
פתח את `index.html` והחלף את הערכים הבאים:

| Placeholder | הסבר | דוגמה (קריות) |
|---|---|---|
| `{{BRANCH_NAME}}` | שם הסניף | `קריות` |
| `{{BRANCH_NICKNAME}}` | כינוי הסניף | `אלופי הקריות` |
| `{{BRANCH_FOOTER}}` | טקסט פוטר דוח שבועי | `כונני הקריות - גאווה ישראלית!` |
| `{{BANNER_IMAGE}}` | שם קובץ תמונת הבאנר | `krayot-map.png` |

> 💡 **טיפ:** ב-VS Code אפשר להשתמש ב-Ctrl+H כדי להחליף את כל המופעים בבת אחת!

### שלב 3: הוספת תמונת מפה
הוסף תמונת באנר לתיקיית הסניף עם השם שהגדרת ב-`{{BANNER_IMAGE}}`

### שלב 4: בדיקה
פתח את `index.html` בדפדפן וודא שהכל עובד תקין 🎉
